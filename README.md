# 出差报销流程导航

一个面向学生和教师的因公出差报销全流程导航网站。

## 功能

- 📋 **首页** — 报销核心步骤概览 + 关键入口卡片
- 🗺️ **流程指南** — 三阶段详细报销流程 + 住宿费限额参考表
- 📥 **文件下载** — 分类下载审批表格与相关材料
- ⚠️ **注意事项** — 最新报销政策提醒与常见问题
- 🔧 **教师管理面板** — 编辑流程步骤、住宿标准、上传文件、管理注意事项

## 教师管理

点击导航栏 **"教师管理"** 按钮进入后台，所有修改自动保存到浏览器 localStorage。

## 使用方式

直接在浏览器中打开 `index.html`，或部署到 GitHub Pages。
