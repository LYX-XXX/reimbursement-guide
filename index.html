PROCESS GUIDE

报销流程指南

按阶段查阅详细流程，确保每一步材料齐全

阶段一

赛前准备材料

  1. 因公出差审批表：出差事由中须注明指导老师及其电话号码；第一行申请理由括号内备注带队老师（示例：xxx 带队老师为西南医院消化内科 xxx，xxx 为医学心理系 xxx）。
  2. 比赛通知（红头文件）：需包含赛事名称、比赛时间、比赛地点，以正式红头文件为准。
  3. 入围名单证明：官方截图或公示文件的打印件，证明团队已进入比赛入围名单。
  4. 飞机票审批：如需乘坐飞机，须满足以下条件 ——
    • 填写《超标准乘坐交通工具审批表》（去程和返程各一份）；
    • 飞机票价格须比当天高铁二等座便宜，提供比价截图（提交给辅导员）。
💡 提示：若带队老师为本学院教员，由带队老师提交出差审批，无需学生另行提交。
阶段二

报销材料准备

  1. 餐补与交通费：无餐补；交通费每人每天 80 元。
  2. 酒店发票：需提前联系酒店前台，将电子发票发至个人邮箱；打印后须彩印，并在每页右下角签署个人姓名。
  3. 会务费 / 交通费：可报销，须提供相应的正规发票。
  4. 团队多人报销：统一只提供一个银行卡号，所有款项汇入该卡。最后需列表汇总：每个人的去程费用、返程费用、酒店费用及实际总报销金额。

阶段三

发票规范与提交要求

  1. 发票彩印与签名：所有发票须彩色打印，并在每页右下角签署个人姓名。
  2. 勤俭节约通知要求：一个团队原则上只由汇报人出差；如需多人同行，带队老师须出具书面材料（如"某某赛事要求这几名学生参加"）。
  3. 医创赛联动规则：同一赛事各队须统一将出差学生写在一张出差表上，实现联动管理。
  4. 整体报销顺序：赛前准备材料 → 提交辅导员 → 大队领导签字 → 学院财务审批 → 有问题打回重提。
⚠️ 注意：审批不通过将被退回重新提交。请仔细检查所有材料，特别是发票规范（彩印 + 签名）和审批表备注信息，避免反复修改延误报销。
